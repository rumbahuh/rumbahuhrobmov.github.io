## Complicaciones
1. Programación orientada a objetos
	Llegados a este punto tuve que cambiar las funciones que checkeaban las posiciones para poder usarlas de una manera expandible.

2. Vecinos
	Para dejar el codigo preparado para la heurística necesitaba tener una manera comprobar los vecinos cercanos de la aspiradora.

	Generé una lista global con Strings "x", "y", "-x" e "-y" para gestionar los vecinos de forma cartesiana generando nuevas poses3d ficticias y así poder ver los caminos cartesianos menos visitados.

	Problema: las nuevas poses ficticias eran demasiado específicas, así que decidí añadir un dt = 0.05 para utilizar un MSE y de manera flexible aproximar posiciones visitadas.
