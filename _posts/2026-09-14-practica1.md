NORTE = (-1, 0)

SUR   = (1, 0)

ESTE  = (0, 1)

OESTE = (0, -1)

	Para dejar el codigo preparado para la heurística necesitaba tener una manera comprobar los vecinos cercanos de la aspiradora.

	Generé una lista global con Strings "x", "y", "-x" e "-y" para gestionar los vecinos de forma cartesiana generando nuevas poses3d ficticias y así poder ver los caminos cartesianos menos visitados.

	Más adelante implementé una lista 'visited' que contiene tuplas de tres elementos, '(x, y, z)' para llevar recuento de las posiciones de pose3d() que el robot ha visitado.
